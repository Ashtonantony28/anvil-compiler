## Notes

- Tier 1 (`anvil.cost.analytic.predict`) evaluates closed-form FSM state durations read off the RTL over each block's dynamic instruction stream, with edge-resolution arbitration of the shared program/data channels, the L1-D and the warp scheduler; it has no fitted parameter. `tier1_closed` is its contention-free closed form.
- Tier 2 learns log(cycles / prior) with LightGBM; `tier2` uses the event model as prior and feature, `tier2_static` only the closed form (no event-level evaluation).
- Cost of a prediction: tier 1 runs a functional profile plus the event model in Python, comparable in wall time to a Verilator run for the largest kernels (see `t_model` / `t_sim` in rows.jsonl.gz); the G4 metric counts timing-backend measurements.
- Because tier 1 is (almost) cycle-exact, tier 2's residual target is ~0 and its trees are nearly empty; tier 2 only adds value over tier 1 where the event model is wrong (SIMT_STACK=1, MEDIC, future RTL changes). `tier2_static` shows what the learned model achieves without the event model.
- The tuning ratio is bounded below by the pools: a perfect model needs 1 measurement, so a pool where random needs E < 10 cannot meet 10 % on its own (e.g. pools with N = 8-12 candidates at the W=2/W=4 configs); the G4 ratio sums over pools. The pools are random samples of the sketch spaces, as random search would draw.
- Rows that timed out on Verilator (2M cycles) are failures, listed per config above, and excluded from tau.
